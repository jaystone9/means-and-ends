Means & Ends reminder keys

This page makes a new key pair for play reminders. It runs only in your browser, and nothing is sent anywhere.

1. Private key (secret)

In GitHub, open the means-and-ends repo, then Settings → Secrets and variables → Actions → New repository secret. Name it VAPID_PRIVATE_KEY and paste this as the value.

2. Public key (safe to share)

Paste this in the chat with Claude.

Then close this page. Reloading it makes a different pair, so copy both from the same visit.
